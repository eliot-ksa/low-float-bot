# بوت تنبيهات اختراق (Donchian + ATR) لأسهم أمريكية → تلغرام

نسخة بايثون من مؤشر TradingView (Breakout Signals) تشتغل تلقائياً عبر
GitHub Actions كل 15 دقيقة خلال ساعات تداول أمريكا، وترسل تنبيه تلغرام
عند تحقق شرط BUY أو SELL — بدون الحاجة لخطة TradingView مدفوعة أو سيرفر دائم.

## الإعداد

1. **ارفع هذا المجلد** إلى ريبو جديد على GitHub (عام أو خاص، الاثنين يشتغلون).

2. **أنشئ بوت تلغرام** عبر @BotFather وخذ التوكن، وابعث أي رسالة له من
   حسابك ثم افتح:
   `https://api.telegram.org/bot<التوكن>/getUpdates`
   لتاخذ رقم `chat.id`.

3. من إعدادات الريبو: **Settings → Secrets and variables → Actions → New
   repository secret**، أضف:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`

4. عدّل قائمة الأسهم في `config.py` (متغير `SYMBOLS`) حسب رغبتك.

5. الجدولة تعمل تلقائياً (ملف `.github/workflows/alerts.yml`). تقدر أيضاً
   تشغلها يدوياً فوراً من تبويب **Actions → Stock Breakout Alerts → Run
   workflow** للتجربة.

## ملاحظات مهمة

- **بيانات yfinance مجانية** ولها تأخير بسيط أحياناً وليست بدقة بيانات
  TradingView تماماً — هذا طبيعي في أي مصدر مجاني.
- **ATR هنا تقريب** لـ `ta.atr` في Pine (باستخدام Wilder's RMA عبر
  `ewm`)، القيم قريبة جداً لكن قد تختلف بأرقام عشرية بسيطة عن TradingView.
- **جدولة GitHub Actions تقريبية**: قد تتأخر التشغيلة بضع دقائق وقت
  الازدحام، وتتوقف تلقائياً إذا صار الريبو خامل (بدون أي commit) لمدة 60
  يوم — شغّل `workflow_dispatch` يدوياً بين فترة وأخرى لو صار الريبو
  غير نشط.
- **useVolFilter و useTrendFilter** مطفّية افتراضياً هنا (مطابقة للقيم
  الافتراضية بكودك). لو تبيها مفعّلة، قول لي وأضيفها بسهولة.
- ملف `state.json` يمنع تكرار نفس التنبيه على نفس الشمعة، ويتحدّث ويُحفظ
  تلقائياً (commit) بعد كل تشغيلة.
